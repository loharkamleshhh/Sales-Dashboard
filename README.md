# 📊 Sales Performance Dashboard | Power BI

## 📌 Project Overview

This is a Power BI dashboard project developed to analyze and visualize sales performance across different regions, categories, products, and cities.

The dashboard transforms raw sales data into actionable business insights through interactive visualizations, KPI tracking, and dynamic filtering. It provides a comprehensive overview of business performance, helping stakeholders monitor sales trends, profitability, and operational efficiency.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Track total revenue, profit, and orders.
- Monitor monthly sales trends.
- Compare sales performance across regions.
- Analyze category-wise sales contribution.
- Evaluate city-wise sales and profit distribution.
- Identify products with the highest profit margins.
- Build an interactive dashboard using slicers and filters.

---

## 📈 Key Performance Indicators (KPIs)

- 💰 Total Sales
- 💵 Total Profit
- 📊 Profit Margin %
- 🛒 Total Orders

---

## 📊 Dashboard Features

- Interactive KPI Cards
- Monthly Sales Trend Analysis
- Regional Sales Comparison
- Category-wise Sales Analysis
- City-wise Sales Distribution
- City-wise Profit Contribution
- Product Profit Margin Analysis
- Dynamic Filters & Slicers
- Interactive Report Navigation
